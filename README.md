# The Internet in One Word — make.fun entry

`main.py` writes one word, "Unsupervised", to `/output/entry.txt`.

Run it with `python3 main.py`. Set the `OUTPUT_PATH` environment variable to override the output path, for example: `OUTPUT_PATH=/tmp/entry.txt python3 main.py`.
